GitHub Issues on this repository is the configured tracker for maps, specs, tickets, and day-to-day work (`gh issue ...`).
This is a durable project fact, pinned in the maintainer-local `~/.agents/factory/POLICY.md`; do not migrate mid-flight.

Exception: the `quality-pass-first-principles` tickets live as maintainer-local markdown under `~/.agents/factory/tickets/jq-pointer/` by user decision (2026-09-27), not as GitHub issues.
